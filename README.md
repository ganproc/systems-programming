# Systems Programming

This repository is my personal learning space for studying systems programming, understanding how software interacts with hardware and operating systems, and developing a deeper understanding of how computers work.

I use multiple programming languages to explore the same concepts from different perspectives, understand their design decisions, compare their trade-offs, and appreciate how different languages approach low-level programming.

This repository is a work in progress and will continuously evolve as I learn, experiment, make mistakes, and improve.
